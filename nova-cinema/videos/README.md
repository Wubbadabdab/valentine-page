# Videos

Put your trailer reel here as **`one-piece-trailer.mp4`**. It plays silently on a loop behind the Movies page hero, with pause and sound buttons in the corner.

If the file is missing, the hero simply shows its animated gradient and the video controls hide themselves.

Every film's trailer and theme song also plays in a pop-up player, embedded from YouTube, so the site has plenty of video even without a local file.
